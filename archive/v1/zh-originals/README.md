# zh-originals — Chinese originals of the mechanism docs

The English mechanism pages are adaptations. These are the originals, published lightly sanitized: absolute paths, machine fingerprints, private project names, and personal data were removed or generalized; every removal was logged in a private redaction record. Content, structure, dates, and statistics are otherwise unchanged — including the parts where the system corrects itself.

## Included

| File | English counterpart |
|---|---|
| `standing-cost.md` | `mechanisms/standing-cost.md` |
| `rule-audit.md` | `mechanisms/rule-audit.md` |
| `maintenance.md` | `mechanisms/maintenance.md` |
| `templates.md` + `dispatch.md` | `mechanisms/dispatch-templates.md` — the English page merges the delegation-template kit and the dispatch principles into one document |

`dispatch.md` contains the model routing table — a dated consumable, kept as-is per the honesty-label policy.

## Not included, on purpose

- **judgment** — the original's positive/negative examples come from real private projects. The English page (`mechanisms/judgment.md`) rewrote every example as a generic scenario; publishing the original would undo exactly that.
- **build-registry** — the live registry contains a private repo layout and absolute paths. The mechanism ships as a blank-template description instead (`mechanisms/build-registry.md`).
- **intake-court** — the rules live in the header of the live intake ledger, whose 34 entries name private sources. The English page (`mechanisms/intake-court.md`) is self-contained.
- **environment notes (ENV)** — machine fingerprints throughout; the trap *patterns* are published in `environment/` instead.
